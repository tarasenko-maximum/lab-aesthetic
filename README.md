# Lab Aesthetic — site (SR/RU)

Kozmetički studio Lab Aesthetic, Kralja Aleksandra 14, Novi Sad.

- `index.html` — ceo sajt (jedan fajl, bez build koraka), SR/RU prekidač gore desno.
- `photos/` — fotografije (stock, zameniti pravim fotografijama salona kad budu dostupne).
- Forma za zakazivanje šalje WhatsApp poruku na broj salona (nema servera).

## Šta treba potvrditi sa salonom
1. Tačan Instagram profil (korišćeno: @kozmeticki_studio_labestetic).
2. Radno vreme (na sajtu: pon–ned 10:00–20:00).
3. Cenovnik — namerno nije izmišljen; dodati cene po uslugama kad ih salon pošalje.
4. Prave fotografije enterijera i tretmana.

Deploy: GitHub Pages, grana `main`.
